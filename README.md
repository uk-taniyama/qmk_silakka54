# silakka54led

This repository is a modified version of **silakka54** with LED support for the **RP2040 Zero**.

The QMK-related source code is based on the original project below, and has been adapted to enable LED control on the RP2040 Zero board.

Original repository:  
https://github.com/Squalius-cephalus/silakka54

## Overview

- Based on the original **silakka54** QMK firmware
- Modified to support LEDs on **RP2040 Zero**
- Intended for custom keyboard firmware experimentation

## Credits

All original work belongs to the author of the silakka54 project.  
This repository focuses on hardware-specific LED functionality for RP2040 Zero.
